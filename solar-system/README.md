# Planetary Science: Understanding Our Solar System Through Data

## Project Overview

Planetary Science is a React-based web application designed to help users explore and understand the solar system through scientific planetary data and visual comparisons.

Rather than focusing only on planetary images, this project highlights important planetary properties such as:

- Mass
- Diameter
- Gravity
- Density
- Temperature
- Orbital characteristics

By comparing these features, users can better understand how planets form, behave, and interact within the solar system.

## About the Project

Each planet in our solar system has unique physical characteristics. This application provides interactive and visual comparisons that help users identify the differences between:

- Terrestrial planets
- Gas giants
- Ice giants

The platform transforms complex astronomical data into a simple, engaging, and educational experience through modern web technologies and clean UI design.

## Features

- Interactive planetary data display
- Dynamic rendering using React
- Reusable component-based architecture
- Responsive design
- Visual comparison of planetary properties
- Educational and user-friendly interface

## Technologies Used

- React.js
- JavaScript

## Learning Objective

The goal of this project is to combine science, education, and technology to create an interactive platform that makes learning about the solar system more engaging and data-driven.

## Running the Project Locally

To run this project locally, ensure you have the following tools installed on your system: Node.js, npm (Node Package Manager), Git, and a code editor such as VS Code.

Start by cloning the project repository from GitHub to your local machine. Once cloned, open the project folder in your code editor so you can access and manage the files easily.

After opening the project, install all required dependencies by running the install command in your terminal. This step downloads all the packages needed for the application to run properly.

Once the installation is complete, start the development server using the project’s start command. After the server runs successfully, a local URL (usually shown in the terminal) will be generated. Open this URL in your browser to view the application.

During development, the project supports live reloading, meaning any changes made to the code will automatically reflect in the browser without needing to refresh manually.

For production use, the project can be compiled into an optimized build version, which prepares it for deployment on hosting platforms.
