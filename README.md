# Explore Solar System

This is a React web application built as part of a TS Academy software development capstone project.

The application serves as a visual exploration tool for the solar system, displaying planet images and related information in an interactive and engaging format. Users can browse through celestial bodies and learn basic details about each planet in a clean and user-friendly interface.

## Features

- Planet images and information display
- Contact form
- Responsive user interface
- Built with React

## Technologies Used

- React
- JavaScript
- HTML
- CSS
