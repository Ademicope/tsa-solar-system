# Explore Solar System

This is a React web application built as part of a TS Academy software development capstone project.

## Run the Project Locally

1. Clone the repository

```bash
git clone https://github.com/Ademicope/tsa-solar-system
cd tsa-solar-system/solar-system/
npm install
npm run dev
```
